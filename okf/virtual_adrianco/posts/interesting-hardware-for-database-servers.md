I've been too occupied on other things to keep posting regularly in the last month. The good news is that I'm learning a lot about some new areas.<br /><br />So what is new in hardware? I think there are some interesting trends in server hardware for running databases. The cost base of a mid-sized Solaris/Oracle server with 32-64GB of RAM is dropping fast. A very common platform in this space has been the 8-way UltraSPARC III based V880, moving to the 12-way V1280 and currently the E2900 (a 24 core V1280 chassis with UltraSPARC IV) over the last few years. Prices vary by configuration, and newer systems give you more performance per $, but are of the order of magnitude of $100K (plus the disk subsystem and software licenses - but thats another topic).<br /><br />The two new entrants in this space are Niagara based systems and Opteron based systems, each has its strengths.
