As an antidote to all the grumbling about the lack of an open developers approach to the Apple iPhone I'm going to talk about some projects that are building open phone platforms.<br /><br />I'm a member of the Silicon Valley <a href="http://www.hbmobile.org/">Homebrew Mobile Phone Club</a>, and there are <a href="http://www.opencellphone.org/index.php?title=Main_Page">several</a> <a href="http://www.widgetry.org">projects</a> in existence to create a free, open source, software stack and applications for mobile phones. The hardware parts are available off the shelf, so you can buy a <a href="http://www.trolltech.com/products/qtopia/greenphone">complete open phone</a> or use whatever parts you like. All you need is an enclosure, and you are on your way to whatever spec you wanted, with whatever applications you wanted.<br /><br />Actually, if someone out there knows Autocad and wants to help design some enclosures, the assistance would be appreciated.
